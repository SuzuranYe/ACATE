## §1 素材

[返回顶部](#toc)

<a id="s1-1"></a>
### §1.1 整理范围

[返回顶部](#toc)

- 源文件夹内的照片和视频都在整理范围内。
- 同一次拍摄的 RAW 和 JPG 算一帧，文件各自移动。
- 其它文件不处理。

<a id="s1-2"></a>
### §1.2 设备时钟

[返回顶部](#toc)

- 整理之前先核实每台设备的时钟。
- 核实的方法：
  - 比较两台设备在同一时刻拍摄的素材；
  - 比较画面中的时钟、日出日落和班次时间；
  - 以手机时间为基准。
- 相机没有调到当地时区的，也按钟差处理。
- 视频记下的时间可能是 UTC，与同一设备的照片比较后核实。
- 有钟差的设备写入 `clock_offsets`（[ACATE_Spec_Contracts〈§3 Itinerary〉](ACATE_Spec_Contracts.md#s3)）。

　　[例]\
　　　　钟差：相机比手机慢 1 小时，`seconds` 写 3600

<a id="s2"></a>
## §2 查看与视觉观察

[返回顶部](#toc)

<a id="s2-1"></a>
### §2.1 查看方式

[返回顶部](#toc)

- 查看原片、代理图或视频抽帧，都算查看了这份素材，效力相同。
- 判断视频的拍摄地点和归属，查看一帧即可。

<a id="s2-2"></a>
### §2.2 视觉观察

[返回顶部](#toc)

- 观察只记画面中直接看得见的事实：
  - 拍了什么、什么场景、人在做什么、有什么交通线索；
  - 看得见的文字、标志、站名、店名和建筑特征；
  - 与前后素材在构图、地点和移动上是否连续。
- 人在哪里，按拍摄者身边的景物判断；标牌上写的目的地、广告和屏幕里的画面只作线索。

<a id="s2-3"></a>
### §2.3 同质集合

[返回顶部](#toc)

- 拍的是同一场景、画面基本一致的一组素材，称为同质集合，可以合写一条观察。
- 合写之前，单独查看第一份、最后一份和看起来与其它不同的素材。
- 延时查看延时总图，不逐帧查看（[ACATE_Spec_Review_Images〈§4.1 延时总图〉](ACATE_Spec_Review_Images.md#s4-1)）。

## §3 分析方法

[返回顶部](#toc)

<a id="s3-1"></a>
### §3.1 查看与比对

[返回顶部](#toc)

- 判断行程，查看足够长的一段连续素材。
- 普通照片分两遍查看：
  - 粗看：把照片按时间分成若干簇，每簇选一张代表，结合定位，找出每处分界大约在哪两份素材之间；
  - 细看：在每个范围里，从最后一份明确还在原处的素材，看到第一份明确已到新处的素材。
- 判断地点，综合标牌、建筑、室内外场景、定位、拍摄时间、前后画面、路线和辅助资料。

<a id="s3-2"></a>
### §3.2 定位

[返回顶部](#toc)

- 手机照片的定位，GPS 定位和基站定位都采用。
- 坐标与前一张完全相同、两张相隔一分钟以上的，可能是手机沿用的旧坐标，结合画面判断。
- 航拍照片的定位是飞行器的位置；拍摄者在哪里，按起降处判断。

<a id="s3-3"></a>
### §3.3 没有定位时的分析

[返回顶部](#toc)

- 相机照片通常没有定位，按下列步骤确定位置：
  1. 对齐时间：把没有定位的素材插到有定位的记录之间；
  2. 借助前后记录：与前后有定位的记录画面连续的，沿用其位置；
  3. 识读画面：把站牌、招牌、地标和地形，与地图、街景和官方图片比对；
  4. 查询资料：对照时刻表、订单和票据。
- 仍定不了的，归入上一个地点。

<a id="s4"></a>
## §4 辅助资料

[返回顶部](#toc)

<a id="s4-1"></a>
### §4.1 辅助资料的用法

[返回顶部](#toc)

- 辅助资料由用户提供，常见的有机票、车票、船票、酒店订单、门票、行程单和手写的旅行记录。
- 资料只用来确定地点、时间和交通，由 AI 阅读分析。
- 证件号、姓名和金额不抄入任何成果。
- 资料与画面不一致的，以画面为准；订单上的时刻是计划时刻，实际到离按素材判断。
