## §1 定位

[返回顶部](#toc)

<a id="s1-1"></a>
### §1.1 用途

[返回顶部](#toc)

- ACATE 引导 AI 整理旅行素材，产出供人核对的行程表、审查图和逐文件的移动指南。
- ACATE 轻量灵活，具备跨平台兼容性，适用于日常整理，按几十个地点、几千份素材的规模设计。
- 给用户看的成果一律用中文。

<a id="s1-2"></a>
### §1.2 核心功能

[返回顶部](#toc)

- 工具包的核心功能有三项：
  1. 地点判断：判断素材在哪里拍摄，并出图呈现该地点的情况；
  2. 延时判断：从素材中找出延时，并判断延时的质量；
  3. 文件夹整理：按行程段整理目标文件夹。
- 其余内容都服务于这三项功能。

<a id="s1-3"></a>
### §1.3 两份成果

[返回顶部](#toc)

- 成果有两项：
  - 行程表：写明哪段时间在哪里、哪段时间在移动（[ACATE_Spec_Workbook〈§1 行程表〉](ACATE_Spec_Workbook.md#s1)）；
  - 移动指南：写明每个文件的原路径和目标路径（[ACATE_Spec_Workbook〈§2 移动指南〉](ACATE_Spec_Workbook.md#s2)）。
- 审查图提交用户判断，不属于成果（[ACATE_Spec_Review_Images](ACATE_Spec_Review_Images.md)）。

<a id="s2"></a>
## §2 分工

[返回顶部](#toc)

<a id="s2-1"></a>
### §2.1 AI 的职责

[返回顶部](#toc)

- AI 负责查看画面、阅读辅助资料、查询地图，判断地点、行程和延时。
- AI 把判断结果写入行程文件和延时文件，再运行工具产出成果。
- 无法确定的事项如实写明，不作猜测。

<a id="s2-2"></a>
### §2.2 工具的职责

[返回顶部](#toc)

- 读取器读取拍摄时间和定位，生成代理图，找出延时候选。
- 审查图工具测量延时，标出待判断帧，绘制审查图。
- 工作簿工具核对行程段首尾相接，写出行程表和移动指南。
- 地点和行程由 AI 判断，工具只提供事实。

<a id="s3"></a>
## §3 只读与授权

[返回顶部](#toc)

<a id="s3-1"></a>
### §3.1 只读

[返回顶部](#toc)

- 工具对素材严格只读，只在运行根目录内写入。
- 工具不移动、不改名、不删除任何素材。
- 素材由用户核对后，按移动指南移动。

<a id="s3-2"></a>
### §3.2 隔离工作流

[返回顶部](#toc)

- 建议复制一份素材，使用副本进行整理，原片最好脱机冷备份。
- 工具包本身对素材严格只读，但无法约束 Agent 自身的行为，因此出于素材安全考虑，强烈建议采用此隔离工作流。

<a id="s3-3"></a>
### §3.3 联网查询

[返回顶部](#toc)

- 联网只用于查证地点、地址、坐标、地图、时刻表和官方资料。
- 照片、视频、订单和票据不上传到任何网站。
- 网站拒绝访问的，不绕开限制。

<a id="s4"></a>
## §4 未定不阻断

[返回顶部](#toc)

<a id="s4-1"></a>
### §4.1 继续运行

[返回顶部](#toc)

- 个别地点或分界确定不了的，其余内容照常完成。
- 确定不了的内容写明，由用户审查时决定。

<a id="s4-2"></a>
### §4.2 用户决定

[返回顶部](#toc)

- 用户说明的事实和决定优先于规范。
- 用户改过的内容，后续步骤不再改回。
