## §1 认定

[返回顶部](#toc)

<a id="s1-1"></a>
### §1.1 人物所在之处

[返回顶部](#toc)

- 人物明显停在一处、在这里活动的，登记一个地点，写成一个停留段。
- 登记人物实际所在之处，不登记只是拍到的远处。
- 一处之内的某处，有公认的单独名称、人物又是专程去它的，登记该处；否则登记整体。
- 店铺位于住处、车站、机场、购物中心或景区内的，并入该地点；位于其它建筑物内的，单独登记。

　　[例]\
　　　　只是拍到的远处：在江边拍摄对岸的东京塔，登记江边\
　　　　登记整体：在丽江古城里游逛，登记丽江古城\
　　　　并入该地点：在东京站里吃午饭，登记东京站

<a id="s1-2"></a>
### §1.2 认定的线索

[返回顶部](#toc)

- 先认定是哪个地点，再命名。
- 线索依次为：画面中的专名与地标；定位与辅助资料；官方来源。
- 认定后，以可靠的地图交叉核对，核实正式名称、所在城市和有无同名地点。
- 柜台、商品和广告上的品牌，不作为店名。

<a id="s1-3"></a>
### §1.3 确认的标准

[返回顶部](#toc)

- 依据菜单、餐具、装修、位置和前后行程综合判断，属于大概率事件的即可确认，不要求唯一锁定，也不必拍到店名。
- 有多个候选的，依次比较，在前一步能区分的即采用：
  1. 画面：店内的桌椅、装修、菜品与哪一处的网上照片相符，采用哪一处；
  2. 所拍内容与目的：按所拍内容和多数人到此的目的，采用可能性最高的一处；
  3. 距离：最近的一处明显比其它各处近的，采用最近的一处。
- 这三步都区分不了的，在地点卡片上写明待确认。

　　[例]\
　　　　画面相符：定位旁 20 米、30 米各有一家餐厅，30 米那家网上照片里的桌椅与所拍相符，采用 30 米那家\
　　　　所拍内容：定位落在山顶，附近有观景台和一家餐厅，照片拍的都是远处风景，采用观景台

<a id="s1-4"></a>
### §1.4 住宿和用餐

[返回顶部](#toc)

- 每次入住登记一个地点，是否入住以订单为准。
- 认得出店铺的，登记该店铺；认不出、前后都在同一城市的，登记上一级地名。

<a id="s2"></a>
## §2 名称

[返回顶部](#toc)

<a id="s2-1"></a>
### §2.1 命名

[返回顶部](#toc)

- 用当地最通行的名称，名称能说明地点的性质。
- 不同地点同名的，才补城市。
- 认不准的，写上一级地名，不自行起名。

　　[例]\
　　　　最通行的名称：清水寺、京都站\
　　　　补城市：长沙的五一广场\
　　　　上一级地名：京都市区

<a id="s3"></a>
## §3 坐标

[返回顶部](#toc)

<a id="s3-1"></a>
### §3.1 取点的原则

[返回顶部](#toc)

- 坐标取地点本身的视觉中心，即多数人心目中该地点所在的位置。无论谁来、来几次，都是同一个坐标，与人物停留的位置无关。
- 先认定是哪个地点，再取点。
- 每个停留段都须有坐标。认不准是哪一处的，取能确定的、包含它的最小地点的坐标。
- 同一地点只用一个坐标，写到小数点后 5 位。

　　[例]\
　　　　与人物的位置无关：在东京塔脚下围着塔拍摄，坐标仍取东京塔的塔身

<a id="s3-2"></a>
### §3.2 建筑物与区域

[返回顶部](#toc)

- 建筑物取外轮廓：塔取塔身，神社、寺庙取主建筑，桥取桥面。
- 视觉中心一般为形心。形心落在对象之外，或离边缘很近的，取该处截面的中点。
- 数座建筑物连成一体、登记为一处的，取连接部分的中点。
- 区域一般取形心；大部分区域人到不了的，取人能活动的范围的中心。
- 区域内有明确的主体建筑的，取该建筑物。
- 古城、古镇、街区这类，取活动范围中心附近的路口，也可取其商业中心。
- 各种形状的取法见示意图 `Template/ACATE_Template_Visual_Center.png`。

　　[例]\
　　　　连成一体：吉隆坡的双子塔取连廊的中点\
　　　　古城的商业中心：丽江古城取四方街

<a id="s3-3"></a>
### §3.3 交通地点

[返回顶部](#toc)

- 车站取站房，有多座的取主站房；没有站房的取站台。
- 地铁站取站台；多线换乘的，取最大的一块。
- 机场取航站楼，分开的数座航站楼取最大的一座。
- 码头取船舶停靠的那一座。
- 巴士站取车辆停靠的那段路边。
- 停车场取整个场地。

　　[例]\
　　　　机场：取最大的国际航站楼

<a id="s3-4"></a>
### §3.4 坐标来源

[返回顶部](#toc)

- 在 OpenStreetMap 上查到地点，取其地物的视觉中心。
- 地图查不到的，取室外定位的中位数。
- 用户给出的坐标优先。

<a id="s3-5"></a>
### §3.5 核验

[返回顶部](#toc)

- 坐标在地点卡片上核验，看是否落在对的地物上。
- 卫星影像上，高楼有投影偏差，以地图的地面轮廓或影像上的墙脚为准。
- 地图没有该地物的，按影像上地物的地面范围取视觉中心。
- 地图与影像不一致、判断不了的，按地图取视觉中心。
- 影像上没有该地物的，不能据此否定它存在。
