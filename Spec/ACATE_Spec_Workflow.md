## §1 总览

[返回顶部](#toc)

<a id="s1-1"></a>
### §1.1 步骤总览

[返回顶部](#toc)

- 整理分为七步，依次进行：

| 步骤 | 工作内容 | 提交用户的材料 |
|---|---|---|
| [〈§2.1 第一步_素材读取〉](#s2-1) | 读取拍摄时间和定位，生成代理图，找出延时候选 | 素材概况 |
| [〈§2.2 第二步_视觉观察〉](#s2-2) | 查看画面，写下视觉观察 | 无 |
| [〈§2.3 第三步_辅助资料〉](#s2-3) | 阅读订单、票据这类资料 | 无 |
| [〈§2.4 第四步_地点判断〉](#s2-4) | 判断地点，取坐标 | 地点卡片 |
| [〈§2.5 第五步_行程编排〉](#s2-5) | 排出行程段 | 当天总图、分界图 |
| [〈§2.6 第六步_延时判断〉](#s2-6) | 判断延时 | 延时总图、延时判断图 |
| [〈§2.7 第七步_成果输出〉](#s2-7) | 写出行程表和移动指南 | 行程表、移动指南 |

<a id="s1-2"></a>
### §1.2 运行根目录

[返回顶部](#toc)

- 每次整理使用一个运行根目录，放在源文件夹之外。
- 运行根目录的结构见[ACATE_Spec_Contracts〈§1 运行根目录〉](ACATE_Spec_Contracts.md#s1)。
- 用户改动内容的，从受影响的步骤继续，不从头重来。

<a id="s2"></a>
## §2 步骤

[返回顶部](#toc)

<a id="s2-1"></a>
### §2.1 第一步_素材读取

[返回顶部](#toc)

- 输入：源文件夹。
- 工作内容：运行 `scan` 和 `find`（[ACATE_Spec_Tools〈§1 读取器〉](ACATE_Spec_Tools.md#s1)），核实设备时钟（[ACATE_Spec_Rules_Media_and_Sources〈§1.2 设备时钟〉](ACATE_Spec_Rules_Media_and_Sources.md#s1-2)）。
- 产出：`Media.jsonl`、代理图、延时文件。
- 提交用户的材料：素材总数，照片、视频各多少，有定位的多少，没有拍摄时间的多少，延时候选几组。
- 通过条件：拍摄时间可用，设备时钟已核实。

<a id="s2-2"></a>
### §2.2 第二步_视觉观察

[返回顶部](#toc)

- 输入：代理图、`Media.jsonl`。
- 工作内容：按[ACATE_Spec_Rules_Media_and_Sources〈§2 查看与视觉观察〉](ACATE_Spec_Rules_Media_and_Sources.md#s2)和[ACATE_Spec_Rules_Media_and_Sources〈§3 分析方法〉](ACATE_Spec_Rules_Media_and_Sources.md#s3)查看画面，先粗看全程，再细看每处变化。
- 产出：视觉观察，形式不限。
- 提交用户的材料：无。
- 通过条件：每一天都已查看。

<a id="s2-3"></a>
### §2.3 第三步_辅助资料

[返回顶部](#toc)

- 输入：用户提供的辅助资料；没有的，跳过这一步。
- 工作内容：按[ACATE_Spec_Rules_Media_and_Sources〈§4 辅助资料〉](ACATE_Spec_Rules_Media_and_Sources.md#s4)提取时间、地点和交通。
- 产出：可用于判断地点和行程的事实。
- 提交用户的材料：无。
- 通过条件：资料都已阅读。

<a id="s2-4"></a>
### §2.4 第四步_地点判断

[返回顶部](#toc)

- 输入：前几步的记录。
- 工作内容：
  - 按[ACATE_Spec_Rules_Places〈§1 认定〉](ACATE_Spec_Rules_Places.md#s1)判断地点，按[ACATE_Spec_Rules_Places〈§3 坐标〉](ACATE_Spec_Rules_Places.md#s3)取坐标；
  - 每个地点画一张地点卡片，一批提交用户，待确认的排在最前（[ACATE_Spec_Review_Images〈§2.1 地点卡片〉](ACATE_Spec_Review_Images.md#s2-1)）。
- 产出：地点卡片。
- 提交用户的材料：地点卡片。
- 通过条件：用户已看过，提出的修改已改好。

<a id="s2-5"></a>
### §2.5 第五步_行程编排

[返回顶部](#toc)

- 输入：确认后的地点和前几步的记录。
- 工作内容：
  - 按[ACATE_Spec_Rules_Itinerary](ACATE_Spec_Rules_Itinerary.md)排出行程段，写入 `Itinerary.json`；
  - 每天画当天总图和分界图（[ACATE_Spec_Review_Images〈§3 行程〉](ACATE_Spec_Review_Images.md#s3)）。
- 产出：`Itinerary.json`、当天总图、分界图。
- 提交用户的材料：当天总图、分界图。
- 通过条件：用户已看过，提出的修改已改好。

<a id="s2-6"></a>
### §2.6 第六步_延时判断

[返回顶部](#toc)

- 输入：延时文件、`Itinerary.json`。
- 工作内容：
  - 每条延时画一张延时总图，按[ACATE_Spec_Rules_Time_Lapse](ACATE_Spec_Rules_Time_Lapse.md)判断；
  - 判断不了的，画延时判断图（[ACATE_Spec_Review_Images〈§4.2 延时判断图〉](ACATE_Spec_Review_Images.md#s4-2)）；
  - 填写地点，把 `confirmed` 改为 `true`。
- 产出：延时文件、延时总图、延时判断图。
- 提交用户的材料：延时总图、有待判断帧的延时判断图。
- 通过条件：待判断帧都已确定。

<a id="s2-7"></a>
### §2.7 第七步_成果输出

[返回顶部](#toc)

- 输入：`Itinerary.json`、延时文件。
- 工作内容：运行 `build`（[ACATE_Spec_Tools〈§3 工作簿工具〉](ACATE_Spec_Tools.md#s3)），写出行程表和移动指南。
- 产出：`ACATE_Timeline.xlsx`、`ACATE_Move_Guide.csv`。
- 提交用户的材料：行程表、移动指南。
- 通过条件：用户确认后，按移动指南移动素材。

<a id="s3"></a>
## §3 提问与自主推进

[返回顶部](#toc)

<a id="s3-1"></a>
### §3.1 最小问题

[返回顶部](#toc)

- 规则和资料能回答的，不问用户。
- 问题集中提出。
- 只问会改变结果的事项。
- 每个问题写明位置、看到的内容、几种可能和建议。

<a id="s3-2"></a>
### §3.2 自主推进

[返回顶部](#toc)

- 用户答复之前，按建议继续后面的工作。

　　[例]\
　　　　最小问题：第 3 段在清水寺一带，画面中没有招牌，可能是清水寺，也可能是相邻的地主神社，建议登记清水寺
