<a id="t1"></a>
## 素材

| 术语 | 定义 |
|---|---|
| 素材 | 要整理的照片和视频 |
| 原片 | 素材的原始文件 |
| 代理图 | 为查看而生成的缩小图；查看代理图即查看原片 |
| 源文件夹 | 素材原来所在的文件夹 |
| 运行根目录 | 一次整理所用的目录，工具只在这里写入 |
| 辅助资料 | 用户提供的订单、票据和行程记录 |
| 钟差 | 设备时钟与当地时间相差的量 |

<a id="t2"></a>
## 地点

| 术语 | 定义 |
|---|---|
| 地点 | 人物停留之处，有一个名称和一个坐标 |
| 坐标 | 地点本身的视觉中心，写到小数点后 5 位 |
| 视觉中心 | 多数人心目中该地点所在的位置 |
| 地点卡片 | 呈现一个地点情况的审查图 |

<a id="t3"></a>
## 行程

| 术语 | 定义 |
|---|---|
| 行程段 | 行程的一段，状态是停留或移动 |
| 停留 | 明显停在一处 |
| 移动 | 从一处前往另一处 |
| 分界 | 相邻两段之间的时刻，是人物实际到达、离开那一刻的最佳估计 |
| 连续行程 | 每一刻都属于一个行程段、没有空档也没有重叠的行程 |

<a id="t4"></a>
## 延时

| 术语 | 定义 |
|---|---|
| 延时 | 同一台机身以有规律的间隔连续拍下的一组照片 |
| 延时序列 | 实际做成延时的帧 |
| 待判断帧 | 审查图工具标出、等待判断的帧 |
| 抖动 | 相邻两帧整幅画面错开的量，单位是原片像素 |

<a id="t5"></a>
## 成果

| 术语 | 定义 |
|---|---|
| 行程表 | 一个行程段一行的 Excel 表 |
| 移动指南 | 写明每个文件原路径和目标路径的 CSV 文件 |

<a id="t6"></a>
## 审查图

| 术语 | 定义 |
|---|---|
| 审查图 | 提交用户判断的图 |
| 当天总图 | 一天的第一张审查图 |
| 分界图 | 呈现分界两侧素材的审查图 |
| 延时总图 | 呈现一条延时的审查图 |
| 延时判断图 | 放大比较几帧的审查图 |
