## §1 行程段

[返回顶部](#toc)

<a id="s1-1"></a>
### §1.1 停留与移动

[返回顶部](#toc)

- 行程由行程段组成，每段的状态是停留或移动。
- 停留：明显停在一处。
- 移动：从一处前往另一处。
- 在行驶的交通工具上拍的素材，归入移动。

<a id="s1-2"></a>
### §1.2 连续与交替

[返回顶部](#toc)

- 从第一段的开始到最后一段的结束，每一刻都属于一个行程段，没有空档，也没有重叠。
- 每段的结束就是下一段的开始。
- 工作簿工具核对这一点。
- 没有素材的时间同样登记。
- 晚上最后一张照片在外、第二天早上才有下一张的，视为回住处过夜。

　　[例]\
　　　　首尾相接：京都站 07:40～09:15，巴士 09:15～09:50，清水寺 09:50～12:30

<a id="s2"></a>
## §2 分界与时间

[返回顶部](#toc)

<a id="s2-1"></a>
### §2.1 分界的估法

[返回顶部](#toc)

- 分界是人物实际到达、离开那一刻的最佳估计。
- 估法依次为：先看证据；证据不够的，取最简单、最日常的解释。
- 分界落在前一段最后一份记录与后一段第一份记录之间的空隙内。

<a id="s2-2"></a>
### §2.2 精度

[返回顶部](#toc)

- 行程表的时刻到分钟，四舍五入。
- 不足半分钟的段，并入相邻的段。

<a id="s2-3"></a>
### §2.3 当地时间

[返回顶部](#toc)

- 时刻一律写当地时间。
- 跨时区的移动段，开始和结束各写各的当地时间。
- 跨午夜的段不切分。

<a id="s3"></a>
## §3 交通

[返回顶部](#toc)

<a id="s3-1"></a>
### §3.1 交通方式

[返回顶部](#toc)

- 移动段须写交通方式，写法不作限定。

　　[例]\
　　　　交通方式：步行、巴士、新干线、CA1234

<a id="s3-2"></a>
### §3.2 素材的归属时刻

[返回顶部](#toc)

- 行程素材按一个时刻归属：照片看拍摄时刻，视频看开始录制的时刻。
- 行程段按 `[start, end)` 计，恰好等于结束时刻的素材归入下一段。
