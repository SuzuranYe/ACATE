## §1 通则

[返回顶部](#toc)

<a id="s1-1"></a>
### §1.1 颜色

[返回顶部](#toc)

- 字和底色用暖灰，待确认和待判断用红色，交通用棕色，延时首末帧用紫色，手机定位用蓝色。
- 分界图中，停留一段的底用浅绿，移动一段的底用浅橙。

<a id="s1-2"></a>
### §1.2 字和版式

[返回顶部](#toc)

- 图宽 2400 像素，只用一种字体，以粗细和颜色区分层次。
- 字体由工具按系统选取（[ACATE_Spec_Tools〈§4.2 系统〉](ACATE_Spec_Tools.md#s4-2)）。
- 只放判断所需的信息。

<a id="s1-3"></a>
### §1.3 地图

[返回顶部](#toc)

- 地图用 OpenStreetMap 和 Esri World Imagery 的底图，图上写明来源。
- 地图由工具绘制。

<a id="s2"></a>
## §2 地点

[返回顶部](#toc)

<a id="s2-1"></a>
### §2.1 地点卡片

[返回顶部](#toc)

- 每处一张：街道图、卫星图、当地拍的照片、名称、地址、介绍和坐标。
- 全部地点一批提交用户，待确认的排在最前，写明待确认的内容。
- 示例：`Template/ACATE_Template_Place_Card.png`。

<a id="s2-2"></a>
### §2.2 视觉中心图

[返回顶部](#toc)

- [ACATE_Spec_Rules_Places〈§3.2 建筑物与区域〉](ACATE_Spec_Rules_Places.md#s3-2)的示意图，各项目不画。
- 示例：`Template/ACATE_Template_Visual_Center.png`。

<a id="s3"></a>
## §3 行程

[返回顶部](#toc)

<a id="s3-1"></a>
### §3.1 当天总图

[返回顶部](#toc)

- 每天一张：每个行程段一行，写名称、时刻、时长和素材数；右侧是当天的地图、待确认的事项和备注。
- 示例：`Template/ACATE_Template_Day_Overview.png`。

<a id="s3-2"></a>
### §3.2 分界图

[返回顶部](#toc)

- 每张至多五处分界：中间是分界时刻，两侧是这两段最近的各三份素材。
- 示例：`Template/ACATE_Template_Boundary.png`。

<a id="s4"></a>
## §4 延时

[返回顶部](#toc)

<a id="s4-1"></a>
### §4.1 延时总图

[返回顶部](#toc)

- 每条延时一张：开头和结尾的帧、抖动的数值、待判断帧、抖动散点图和结论。
- 示例：`Template/ACATE_Template_Time_Lapse.png`。

<a id="s4-2"></a>
### §4.2 延时判断图

[返回顶部](#toc)

- 有判断不了的帧时才画：放大这几帧，供用户比较。
- 示例：`Template/ACATE_Template_Time_Lapse_Judge.png`。
