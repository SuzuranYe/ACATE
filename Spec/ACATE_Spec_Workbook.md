## §1 行程表

[返回顶部](#toc)

<a id="s1-1"></a>
### §1.1 行程表的列

[返回顶部](#toc)

- 行程表只有一张，文件名 `ACATE_Timeline.xlsx`，一个行程段一行：

| 列 | 内容 |
|---|---|
| 开始 | 这一段的开始，到分钟 |
| 结束 | 这一段的结束，到分钟 |
| 状态 | 停留或移动 |
| 地点或路线 | 停留写地点，移动写「起点 → 终点」 |
| 坐标 | 停留写坐标，5 位小数；移动留空 |
| 交通方式 | 移动写交通方式；停留留空 |
| 素材 | 这一段的素材数，有延时的写明几组 |
| 文件夹 | 这一段的文件夹名；没有素材的留空 |

<a id="s1-2"></a>
### §1.2 模板

[返回顶部](#toc)

- 行程表由工作簿工具按 `Template/ACATE_Template_Timeline.xlsx` 写出，版式不手工修改。

## §2 移动指南

[返回顶部](#toc)

<a id="s2-1"></a>
### §2.1 目标文件夹

[返回顶部](#toc)

- 顶层分为照片、视频、延时三类。
- 一个行程段一个文件夹，没有素材的行程段不设文件夹。

```text
照片/04-12 07.40 京都站/
视频/04-12 09.50 清水寺/
延时/04-12 17.02 八坂神社 26mm 867张/
```

<a id="s2-2"></a>
### §2.2 文件夹名

[返回顶部](#toc)

- 停留段写 `MM-DD HH.MM 地点`，移动段写 `MM-DD HH.MM 起点 - 终点`。
- 日期和时刻取这一段的开始，文件夹因此按时间排列。
- 跨午夜的段用开始那天的日期。
- 延时文件夹名写 `MM-DD HH.MM 地点 焦段mm 帧数张`，时刻取延时首帧，一条延时一个文件夹。
- 地点名称中 Windows 不允许的字符，由工具换成连字符。

　　[例]\
　　　　停留段：`04-12 09.50 清水寺`\
　　　　移动段：`04-12 09.15 京都站 - 清水寺`\
　　　　延时：`04-12 17.02 八坂神社 26mm 867张`

<a id="s2-3"></a>
### §2.3 移动指南的内容

[返回顶部](#toc)

- 移动指南是 CSV 文件 `ACATE_Move_Guide.csv`，一个文件一行，写类别、原路径和目标路径。
- 同一文件夹内重名的文件，目标文件名后加序号。
- 没有拍摄时间的文件归入「日期未知」，拍摄时刻在行程之外的归入「行程之外」。
- 工具不移动文件，由用户核对后移动。
